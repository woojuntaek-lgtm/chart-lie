# 차트 거짓말 탐지기

숫자는 그대로인데 두 배 차이? — 데이터 시각화를 손으로 체험하는 앱입니다. 길이·각도·넓이·색 진하기 어림 실험, 게슈탈트 원칙(근접성·유사성·폐쇄성·연결성), 목적(비교·비중·추세)에 맞는 차트 고르기, 비슷한 조각 다섯 개의 파이, 지름 2배가 넓이 4배로 보이는 원, 축 시작값을 바꿔 보는 잘린 축(102 vs 98이 2.33배로), 데이터 잉크, 축을 고정해야 하는 움직이는 차트, 상자 그림과 이상치 경계, 두 봉우리를 숨기는 상자와 바이올린 플롯, 패싯 그리드, 시본 context까지 담았습니다. 빅데이터 08 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 눈: 잘린 막대 사건, 네 가지 방식 어림 실험, 게슈탈트 원칙
- ② 차트: 목적별 막대·파이·선, 비슷한 조각 다섯 개, 퀴즈 ①(네 배)과 넓이 착시
- ③ 잘린 축: 축 시작값 슬라이더(막대·선), 데이터 잉크, plotly 축 고정 애니메이션
- ④ 분포: 상자 그림과 이상치 경계, 퀴즈 ②(195도), 바이올린·히스토그램, 패싯, 시본 context, 세 줄 정리, 생각해 볼 질문
